# Student Academic Performance Analysis

## Overview
An end-to-end Data Analytics project designed to analyze student grades, department distributions, and attendance metrics using Excel, SQL Server, and Power BI.

## Repository Structure
- **Dataset:** `student_result_data.csv.xlsx`
- **SQL Logic:** `student_data_sql_queries.txt`
- **Power BI Report:** `Students_Performance_Dashboard.pbix`
- **Dashboard Image:** `Screenshot 2026-09-09 232956.png`

## Tech Stack
- **Database / Transformation:** SQL Server (Views, Aggregations, Conditional Logic)
- **Data Source:** Microsoft Excel
- **Visualization:** Power BI Desktop
